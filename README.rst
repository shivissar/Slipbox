Zetteling
=========

A local-first, plain-text Zettelkasten for macOS. Each note is a Markdown file
in a folder you choose; links, tags and threads live inside the files, so your
notes stay readable without the app. Optional AI features (note interrogation,
tag suggestions, related notes) work with Anthropic, OpenAI-compatible
services, Google Gemini, or Ollama running on your own Mac.
