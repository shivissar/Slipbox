# Security

Slipbox is maintained by one person. If you find a security problem in it,
please report it privately, so that it can be fixed before the details are
public.

## How to report a problem

1. Open <https://github.com/shivissar/Slipbox/security/advisories/new>. (Or, on
   the repository's page, click **Security**, then **Report a vulnerability**.)
   You need to be signed in to GitHub.
2. Say which version of Slipbox you use (**Slipbox → About Slipbox**), which
   version of macOS, what you did, what happened, and what you think someone
   could do with it.

Please do not put the details in a public issue. If the form does not work for
you, open an [issue](https://github.com/shivissar/Slipbox/issues) that says
only that you have a security matter to report, and you will be told how to
send the details.

## What to expect

You will get a reply, though it may take some days. A problem that is confirmed
is fixed in a new version of Slipbox, and you are credited in its release notes
if you wish.

## Which versions are covered

Only the newest release receives fixes. The app tells you when a newer version
is out (**Settings → Updates → Check now**), and the newest is always at
<https://github.com/shivissar/Slipbox/releases/latest>.

## What this covers

Slipbox itself: the app, its locked notes, importing and exporting, and its
update check.

Slipbox also contains software written by others, such as pandoc; it is listed
in [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). A problem in one of those
is best reported to its own project. Report it here as well if the way Slipbox
uses it puts your notes at risk.
