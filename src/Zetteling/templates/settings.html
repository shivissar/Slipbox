Embedding provider (for semantic find-related-notes)

Separate from the chat provider because Anthropic does not provide a native embeddings API. Pick Ollama (local, free, private) or any OpenAI-compatible service. The chat and embed providers can be different — for example, Claude for chat and Ollama for embeddings is a sensible privacy-conscious combination.

OpenAI embedding models: text-embedding-3-small (cheap, 1536 dims), text-embedding-3-large (better, 3072 dims). Voyage and other compatible services also work.

Common Gemini embedding models: text-embedding-004 (768 dims), gemini-embedding-001.

Common Ollama embedding models: nomic-embed-text (768 dims, fast), mxbai-embed-large (1024 dims, better quality). Pull with ollama pull nomic-embed-text. If you get a "model not found" error here, the model name in this field does not match what you have pulled in Ollama — run ollama list in a terminal to see exact names.

Voyage AI is Anthropic's recommended embeddings partner. Sign up at voyageai.com to get an API key. Current flagship text embedding model is voyage-3.5 (1024 dims); voyage-3-large is higher quality but more expensive. Domain-specific models exist for finance, law, code, and multilingual text.
