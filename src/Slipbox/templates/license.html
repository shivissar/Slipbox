A note on terminology

The PolyForm Noncommercial license is source-available rather than "open source" in the strict technical sense. The Open Source Definition maintained by the Open Source Initiative prohibits any restriction on field of endeavor, including restrictions on commercial use, so licenses like this one are not OSI-approved open source. They are better described as "source-available" or "freely available for non-commercial use." The distinction matters mostly for people who are careful about licensing terminology. For most users, the practical question is what the use is for: personal use with no commercial aim, or use by a non-profit, educational, public or government body, is allowed; use that serves a business is not.

The PolyForm project is a working group of experienced open-source lawyers who drafted this license specifically to fill the gap between permissive open-source licenses and commercial terms. It has been adopted by a growing number of academic and small-author projects for exactly the reasons Slipbox uses it. The canonical text and FAQ live at polyformproject.org/licenses/noncommercial/1.0.0.

    • certifi (the certificates used for secure connections) is under the Mozilla Public License 2.0. It ships unmodified, as source code.
    • numpy (used to find related notes) is under a BSD licence and bundles OpenBLAS and LAPACK (BSD), the GCC runtime library (GPL 3 with the GCC Runtime Library Exception) and libquadmath (GNU Lesser General Public License 2.1 or later; source at gcc.gnu.org).

    Each package’s licence text is inside the app with the package. The full list, with versions, is in THIRD-PARTY-NOTICES.md in the source code on GitHub.
